# 测试与首次运行

## 1. 自动检查

在仓库目录执行：

```sh
npm test
npm run check
npm run build
```

需要 Node.js 22+，不需要安装依赖。测试使用 Node 内置工具，覆盖单位换算、非零原点、负边距、自动填满、百分比、去重、语法重复/块/变量/循环报错、预设格式，以及模拟宿主上的上下文校验和失败恢复。

宿主模拟测试不等于 Illustrator 实机测试。

## 2. 浏览器界面预览

```sh
npm run preview
```

打开 http://127.0.0.1:4173，退出时按 Ctrl+C。

- 在 260–400 px 宽度检查表单；只能出现灰度，不加载外部字体或图标库。
- 改为 6 列、8 行，观察计算尺寸和参考线数量变化；界面不显示图形预览。
- 不应出现单位下拉框。分别输入 10px、3mm、5%，以及不带单位的 10；最后一种应使用文档标尺单位。
- 清空列数，设置列宽 20 mm，确认自动填满；列数为 0 时保留左右边距参考线。
- 输入过大间距，确认报错且生成不可用。
- 自定义输入 `$c = | ~ |` 换行 `$c*3 (v)`，状态应显示 4 条参考线，实际生成在 Illustrator 中测试。
- 保存、编辑、删除预设；导出后重新导入，参数应一致。

浏览器不连接 Illustrator，文档修改按钮禁用，不能用它验收宿主功能。

自动界面检查（需要本机安装 Chrome，可用 CHROME_BIN 指定路径）：

```sh
npm run test:ui
```

此测试用临时浏览器配置，不访问你的个人浏览器会话；覆盖 260/320/400 px、中文与英文、混合单位、语法错误和预设保存。浏览器检查语言可使用 ?lang=zh 或 ?lang=en；Illustrator 内忽略此参数，始终采用宿主语言。

## 3. Illustrator 开发安装

先构建，再执行：

```sh
npm run install:dev
```

macOS 开发调试：

```sh
defaults write com.adobe.CSXS.12 PlayerDebugMode 1
```

Windows 开发调试（命令提示符）：

```bat
reg add HKCU\Software\Adobe\CSXS.12 /v PlayerDebugMode /t REG_SZ /d 1 /f
```

重新启动 Illustrator，在窗口菜单的扩展入口打开 gridloom。开发安装路径：

- macOS：`~/Library/Application Support/Adobe/CEP/extensions/studio.gridloom.panel`
- Windows：`%APPDATA%\Adobe\CEP\extensions\studio.gridloom.panel`

## 4. 实机验收

新建专门的测试文档，不直接从重要设计文件开始。

1. 新建 A2（420 × 594 mm）画板。四边输入 24mm、12 列、栏距输入 6mm、行数 0，应得到列宽 25.5 mm 和 24 条纵向参考线与 2 条上下边距线，共 26 条。
2. 生成后检查 gridloom 图层。再生成一次，“替换此范围网格”不应累积参考线；追加模式应保留已有网格。
3. 创建一个手动参考线。使用“本插件参考线”清理，手动参考线应保留。
4. 切换到“范围内全部参考线”，应先出现确认；取消应不改变文档。
5. 测试原生撤销与重做：记录一次生成需要的撤销次数。不要预设各版本都只有一步。
6. 选择单个对象、多个对象、普通组和剪切组。比较几何边界与包含描边模式；剪切组以蒙版为准。
7. 移动画板到非零坐标，重复生成，检查定位。
8. 添加第二个不同尺寸画板，选择所有画板，确认各自计算和写入。
9. 锁定 gridloom 图层或待替换参考线，应显示错误，不能留下部分新增结果。
10. 切换文档、选区和活动画板后生成，确认不会写入旧范围。
11. 运行基线、三分、黄金比例、斐波那契及 16:9 预设；检查自定义错误的行列位置。
12. 改变 Illustrator 界面主题；字体、字号、背景应跟随宿主，强调色仍为灰度。
13. 收起面板，检查新版图标；在 Retina / 100% / 200% 缩放下检查细缝可辨识度。
14. 保存、关闭、重新打开文档，确认 gridloom 参考线归属标记可用于清理。

可以从 Illustrator 的 文件 → 脚本 → 其他脚本 运行 scripts/smoke-illustrator.jsx。它仅创建并关闭自己的临时文档，不保存。执行返回 PASS / FAIL；若从菜单运行无输出，可用 AppleScript 调用查看返回值。

## v3 新功能实测

在 100 × 200 pt 测试画板上：

1. 点击底部重置图标，清空的表单应生成四边外框。
2. 两列，列宽 `10pt | ~ | 10pt`，栏距 `5pt | 5pt`；应有 9 条纵向线，坐标相对左边界为 0、10、35、45、50、55、65、90、100 pt。
3. 自定义输入下方语法：纵向线在 0、20、80、100 pt；水平线距离顶部为 0、20、180、200 pt。

```text
$a = | {20%} | ~ | 20% | (v $WIDTH)
$a (v)
| $a[1] | ~ | $a[1] | (h)
```

4. 输入 `| 1p5 | calc(10pt / 2) | (v)`，线位置为 0、17、22 pt。
5. 输入 `| { | ~ | ~ | (3.6pt) } | ~ | (vpf 10pt)`，线位置应为 0、2、4、10 pt。
6. 保存包含裸数字、百分比和 calc 的网格预设，再切换文档标尺单位后加载：固定尺寸应保持，百分比随范围变化。
7. 输入不存在的捕获 `$a[99]` 或 `calc(2 / 0)`，应报错且禁止生成。英文 Illustrator 应显示英文错误。

本轮 v3 新增逻辑已通过自动测试和浏览器交互测试；上述原生面板步骤仍需用户实测。不会自动关闭或重启你的 Illustrator。

## 测试结束后关闭开发开关

macOS：

```sh
defaults delete com.adobe.CSXS.12 PlayerDebugMode
```

关闭后重启 Illustrator 生效；本地未签名 gridloom 也将无法加载。继续开发测试时可重新设为 1。正式分发应使用签名扩展。

## 0.3.1 修正

- 行数 0 仍绘制已填写的上下边距；列数 0 同样保留左右边距。空边距不增加该侧参考线，明确输入 0 会绘制范围边界。停用的行高、列宽及间距不参与计算。
- 首次打开面板、展开位置与设置、预设保存表单，以及字体变化时，按内容申请调整高度。收起配置后恢复紧凑高度。
- 在浮动面板测试配置展开后是否完整显示；在停靠面板测试底部生成按钮始终可见。部分停靠状态由 Illustrator 限制大小，无法强制撑开；剩余配置可滚动访问。
- CEP 的限制依据 Adobe CSInterface 12 的 resizeContent 文档：https://github.com/Adobe-CEP/CEP-Resources/blob/master/CEP_12.x/CSInterface.js 。自动浏览器测试检查尺寸请求和受限高度下按钮可见性，实机停靠行为仍需确认。

## 0.3.2 参考线显示修正

- 对当前文档进行了只读检查：28 个带 gridloom 标记的对象全部为原生参考线，普通路径为 0；没有修改或保存文档。
- 不再将每条参考线的对象名称写成 gridloom，保留 Illustrator 默认名称。gridloom 图层和内部归属标记保留，清理与替换不受影响。已有对象名称不会自动修改，重新生成后使用新行为。

## 0.3.3 产品名

产品显示名统一为 `gridloom`：窗口标题、扩展菜单、界面文案、默认图层与文档。内部扩展 ID 和预设存储不变。生成时复用旧版大写名称的图层并改为小写，避免重复创建图层；参考线对象仍保留 Illustrator 默认名称。现有文档不会因安装而自动改动。

## 0.3.4 稳定标签页布局

- 三个标签页共用网格表单的高度，切换时不调整宿主窗口；长预设列表、自定义语法说明在页内滚动。
- 状态消息固定占用两行，长错误可在消息区域滚动，不推挤生成按钮。
- 展开配置栏和保存表单仍自动适配高度；重新聚焦面板不会强制收缩用户调整过的高度。
- 浏览器回归检查覆盖中英文、260/320/400 px 下反复切换时窗口尺寸请求和底部位置稳定，以及长列表滚动。实际停靠状态仍由 Illustrator 控制。

## 0.3.5 自动范围

面板移除范围选择与所有画板选项。有选区时使用对象整体边界，无选区时使用当前画板。生成及清理前重新读取范围。切换回面板时刷新。此行为不自动改写边距和网格参数，参数放不下仍会报错。

## 0.3.7 预设卡片与参考线锁定

预设页第一格“＋ 添加”保存当前设置，替代底部书签。内置及自存预设显示计算生成的示意缩略图；选择后留在预设页，可直接生成。自存预设保留编辑、删除及导入导出。锁按钮调用 Illustrator 原生 lockguide 命令切换全局参考线锁定；不显示未经宿主确认的锁定状态。此原生命令仍需用户实机验收。

## 0.3.8 中间内容区滚动

仅标签页内容、位置与设置、保存表单所在的中间区域滚动。顶部快捷工具和标签栏、底部状态与生成按钮固定。56 项自动测试及浏览器布局回归通过，包含受限高度下滚动时顶底位置不变。安装后重新打开面板，展开位置与设置并缩小窗口，确认滚动条只出现在中间区域；Illustrator 实际停靠表现待用户验收。

## 0.3.9 状态与性能

经用户确认，锁定和显示改为操作 gridloom 图层，取代 0.3.7 的全局菜单切换。按钮采用亮色/灰色和对应图标，无边框或悬停提示。状态从图层读取，聚焦时同步；无图层时禁用。全局参考线显示与图层显示互相独立。

58 项单元测试和浏览器回归通过，包括图层状态、无图层、外部修改后聚焦同步、追加跳过 10000 个旧对象、标签切换复用计算。没有进行本版本原生宿主计时测试。

实机验收：生成后点击锁及眼睛，确认图层面板状态和按钮一致；在图层面板更改后回到 gridloom 检查同步；保持另一普通图层不受影响。解锁并显示 gridloom 图层后测试生成，分别测试追加和替换。
